← Documentation root

This index covers the architecture documentation for the personal portfolio application. Each document focuses on one architectural concern. Together they describe the tech stack, component structure, internationalisation flow, CI/CD pipeline, and runtime data flow.

For a quick orientation, start with overview.md; for the German-language version, see overview.de.md. The remaining documents go deeper into specific areas.
