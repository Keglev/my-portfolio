This index covers the frontend documentation for the portfolio application. Each document focuses on one frontend concern: component interfaces, navigation structure, visual styling, or internationalisation.

For component props and usage, start with components.md. For how the visual appearance is constructed, see styling.md. For adding or modifying text content in any language, see localization.md. For the scroll-based navigation model, see routing.md.
