ProjectCard()

Renders a single project card with a lazy-loaded image, localised description, technology tags, and links to the GitHub repository and (optionally) a live URL. Image loading follows a three-step fallback chain: 1. Explicit `image` prop or bundled public-folder asset 2. Raw GitHub content on the `main` branch 3. Raw GitHub content on the `master` branch → SVG placeholder → 1×1 transparent GIF

 Pre-resolved image URL supplied by the parent

 Generates a named SVG placeholder data URL
