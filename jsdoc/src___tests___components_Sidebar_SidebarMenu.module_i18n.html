Module: src/__tests__/components/Sidebar/SidebarMenu.i18n

Real-i18n integration test for SidebarMenu's dynamic NAV_ITEMS key resolution. Every other SidebarMenu test mocks react-i18next (see SidebarMenu.test.js) -- this file deliberately does not. SidebarMenu.js renders its nav labels via t(key) where `key` comes from the NAV_ITEMS array, not a literal string in source (unlike most other components, which call t('some.key') directly). A mocked identity translation (t: (k) => k) would make a typo in NAV_ITEMS or a missing key in en.json/de.json invisible: the mock renders whatever string it's given regardless of whether that key actually resolves in the real locale files. Only a test against the real i18n instance can catch that class of bug, so this one case is kept as a real integration test rather than converted to match the sibling mock pattern.
